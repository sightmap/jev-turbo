`--tools DIR` offers the tools of a sightkick layer to the picker ahead of the page's elements. A picked tool runs through `sightkick call --via cli`; its guidance orders the next options; elements remain the fallback when no tool fits or a call fails. Suites can name a `tools` directory. `bench/saucedemo-tools.json` runs the saucedemo goals over the example tool layer.
