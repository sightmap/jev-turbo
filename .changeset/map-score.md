`jev-turbo score RUN.json ...` prints one column per run file: goals reached, steps per goal, wasted steps, fallback picks, low-confidence picks, candidates offered, low-coverage pages, seconds. `bench` prints the same block after its table. It is a measure of the map: how a 200 ms driver does over it.
